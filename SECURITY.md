# Security policy

## Reporting a vulnerability

If you discover a potential security issue in this project, notify AWS/Amazon Security through the [vulnerability reporting page](https://aws.amazon.com/security/vulnerability-reporting/) or by email to [aws-security@amazon.com](mailto:aws-security@amazon.com).

Do **not** create a public GitHub issue for a security problem.

We take every report seriously. We investigate it and address any vulnerability as quickly as possible.
