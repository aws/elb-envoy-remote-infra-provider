    ELBProxyConfiguration¶

    ELBProxyConfiguration is a CRD for ELB for Envoy proxy configuration.

    ELBProxyConfiguration is a direct Gateway API policy: it attaches to one or more Gateway or GatewayClass resources via spec.targetRefs. When a Gateway is targeted, the ELBProxyConfiguration must live in the same namespace as the Gateway.

    When a GatewayClass is targeted, the ELBProxyConfiguration must live in the controller's own namespace GatewayClass-scope targetRefs from ELBProxyConfigurations in any other namespace are ignored.

    Field Description Default Validation
    apiVersion string gateway.elbproxy.aws/v1alpha1
    kind string ELBProxyConfiguration
    metadata ObjectMeta Refer to Kubernetes API documentation for fields of metadata.
    spec ELBProxyConfigurationSpec
    status ELBProxyConfigurationStatus

    ELBProxyConfigurationStatus¶

    ELBProxyConfigurationStatus defines the observed state of ELBProxyConfiguration

    Appears in: - ELBProxyConfiguration

    Field Description Default Validation
    conditions Condition array Conditions describe the ELBProxyConfiguration.
    Known condition types:
    - "Accepted": True when this is the winning policy for at least one target
    Gateway; False/Conflicted or False/InvalidTargetRef otherwise.
    - "Programmed": True when at least one backing proxy is active. Per-Gateway
    health is in Proxies.
    proxies ProxyStatusEntry array Proxies reports the health of each AWS proxy backing this ELBProxyConfiguration,
    one entry per target Gateway (a merged GatewayClass has one entry).
    Atomic because the key, gatewayRef, is a struct and a listMapKey must be scalar.    		 MaxItems: 32
    observedGeneration integer ObservedGeneration reflects the generation of the most recently observed ELBProxyConfiguration

    GatewayReference¶

    GatewayReference names a Gateway that an ELBProxyConfiguration backs. A merged GatewayClass uses Kind "GatewayClass" and the class name.

    Appears in: - ProxyStatusEntry

    Field Description Default Validation
    kind string Kind of the referent: "GatewayClass" for a merged gateway, else "Gateway". Gateway Enum: [Gateway GatewayClass]
    namespace string Namespace of the referent. Empty for a merged GatewayClass (cluster-scoped).
    name string Name of the referent Gateway (or GatewayClass name for a merged gateway). Required: {}

    ProxyIpConfiguration¶

    Appears in: - ProxyNetworkUserConfiguration

    Field Description Default Validation
    ipAddressingConfiguration ProxyIpAddressingConfiguration IpAddressingConfiguration defines IPv4 and IPv6 addressability settings.
    If unset, defaults are derived from the EnvoyProxy IPFamily:
    IPv4 (default): ipv4=internal, ipv6=off
    IPv6: ipv4=off, ipv6=internal
    DualStack: ipv4=internal, ipv6=internal
    "internal" (default) means VPC-only; use "internet-facing" to expose publicly.
    The ELB Proxy API rejects these combinations: both off; IPv4 internet-facing
    with IPv6 internal; and IPv4 internal with IPv6 internet-facing. Quote "off"
    in YAML, since an unquoted off is parsed as the boolean false.

    ProxyStatusEntry¶

    ProxyStatusEntry reports the health of one AWS proxy backing this ELBProxyConfiguration for a specific target Gateway.

    Appears in: - ELBProxyConfigurationStatus

    Field Description Default Validation
    gatewayRef GatewayReference GatewayRef identifies the Gateway this entry describes. Required: {}
    proxyArn string ProxyArn is the ARN of the AWS proxy backing this Gateway. Empty until known.
    conditions Condition array Conditions describe the health of this proxy.
    Known condition types:
    - "Programmed": True when the proxy is active. False with reason Pending
    (being created), ActionRequired (the AWS status reasons are in the message),
    CreateFailed, or Deleting. After Deleting, the entry is removed on Gateway
    deletion, or moves to Pending on replacement.
